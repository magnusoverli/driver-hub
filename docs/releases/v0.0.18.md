## What’s new

Driver Hub now notifies administrators when a newer stable release is available. Read the new version’s release notes inside the app, ignore that version, or choose **Update**. Ignored versions remain available under **About → Driver Hub updates**.

On supported Linux Compose installations, the optional host updater pulls the exact release image, restarts Driver Hub, and verifies the running version and web interface. If verification fails, it restores the previous image. Site configuration, data volumes, and custom mounts are preserved. Running Nomad driver jobs are not restarted.

## Upgrading to v0.0.18

Upgrade to this release manually. To enable subsequent one-click updates, follow the [one-time host updater setup](https://github.com/magnusoverli/driver-hub/blob/v0.0.18/OPERATIONS.md#optional-managed-updates-from-about). Notifications and in-app release notes work without the host updater.
