Set up a downloaded driver directly from its catalog row. Required settings appear first, and optional settings are collapsed. New devices can start immediately; replacements and drivers needing secret provisioning show the prerequisites before startup.

The device page now leads with the deployment result. **Deployment successful** means the current driver is running and another compatible Nomad client has confirmed a copy of its pinned image. This does not certify spare capacity, device connectivity, or VideoIPath approval. Allocation details, configuration, and history remain available under diagnostics.

Nomad jobs now use readable display names while keeping their stable IDs. Existing jobs pick up the new name on their next start, update, or rollback.
