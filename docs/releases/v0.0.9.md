### First login

Enter the default password once, then choose and confirm a new one. Driver Hub confirms the change and opens the page you originally requested. That browser stays signed in; all previous sessions for the account are invalidated. Later password changes from the account menu still require the current password and sign you out.

### Nomad setup

Allocation log links now use the configured cluster address, including its scheme and port. If operators open Nomad at a different URL, select **Settings → Nomad cluster → Jobs → Use a different address for the Nomad web interface**. Existing overrides are preserved. The **Hub download address** is separate: it tells Nomad clients how to reach Driver Hub for images.

### BuildKit and upgrades

Compose now pulls `moby/buildkit:rootless`, the latest stable rootless worker, and skips unused device and containerd checks at startup. Driver source builds remain off by default.

To upgrade, back up the manager data and replace your local `compose.yaml` with the copy attached to this release. Keep your data volume and `.env`; if you set `DRIVER_HUB_IMAGE`, update that pin to v0.0.9. Run `docker compose pull` followed by `docker compose up -d`. Pulling images alone does not update an older Compose file. No password reset or Nomad reconfiguration is needed.
