New VideoIPath targets default to plain WebSocket (`ws://`). In **Settings → VideoIPath**, enable **Use TLS (secure WebSocket)** for a listener that requires `wss://`. The form previews the URL, including any custom port, before saving.

The endpoint check uses HTTP for WS and certificate-verified HTTPS for WSS. Existing saved secure targets and staged deployments are unchanged. Use plain WebSocket only on a trusted network: the driver sends its registration token unencrypted.
